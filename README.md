# Controle de instabilidade de saldo — Docas

Painel de apontamento e acompanhamento de falhas de migração (KD e local) nas docas.

Abra `index.html` no navegador, ou use o endereço publicado no GitHub Pages.

Os lançamentos ficam no navegador do aparelho (não sobem para o GitHub). Para levar os números de um aparelho a outro, use **Dados → Exportar planilha** e depois **Importar planilha**.
