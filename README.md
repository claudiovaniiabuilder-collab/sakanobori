# Controle de instabilidade de saldo — Docas

Painel de apontamento e acompanhamento de falhas de migração (KD e local) nas docas.

Abra `index.html` no navegador, ou use o endereço publicado no GitHub Pages.

A página publicada abre com os apontamentos do controle local. Lançamentos feitos depois disso ficam no navegador de cada aparelho. Para copiar de um aparelho a outro, use **Dados → Exportar planilha** e depois **Importar planilha**.
